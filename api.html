Xác thực API Key

API của PIIScan Server Pro sử dụng khóa API (API Key) được tạo ra từ bảng quản trị máy chủ để xác thực quyền truy cập.

Bạn cần cung cấp mã API Key này thông qua header HTTP x-apikey trong tất cả các yêu cầu gửi tới server.

Ví dụ gửi yêu cầu cURL 
curl --request GET \
  --url https://api.piiscan.pro/v1/reports/{scan_id} \
  --header 'x-apikey: MA_API_CUA_BAN'

Quét thư mục máy chủ

Yêu cầu máy chủ quét đệ quy toàn bộ các tệp tin trong một đường dẫn thư mục tuyệt đối trên ổ cứng.

POST https://api.piiscan.pro/v1/scan/path

Tham số yêu cầu (JSON Body)

Tham số Mô tả chi tiết
path string Đường dẫn tuyệt đối của thư mục cần quét trên hệ thống (Ví dụ: /var/www/html/uploads). Bắt buộc.
recursive boolean Có thực hiện quét đệ quy các thư mục con hay không. Mặc định là true.
Ví dụ sử dụng Node.js JavaScript 
const axios = require('axios');
 
axios.post('https://api.piiscan.pro/v1/scan/path', {
  path: '/var/www/html/uploads/',
  recursive: true
}, {
  headers: { 'x-apikey': 'MA_API_CUA_BAN' }
}).then(response => {
  console.log(response.data);
});

Quét tệp tin đơn lẻ

Tải lên một tệp tin đơn lẻ trực tiếp từ client để phân tích rủi ro an ninh mạng và dữ liệu cá nhân nhanh chóng trước khi tệp được lưu vào đĩa cứng.

POST https://api.piiscan.pro/v1/scan/file

Tham số yêu cầu (FormData)

Tham số Mô tả chi tiết
file file Dữ liệu nhị phân của tệp tin. Dung lượng tối đa hỗ trợ: 50MB. Bắt buộc.

Truy xuất Báo cáo

Lấy kết quả chi tiết của phiên quét, bao gồm danh sách các vi phạm dữ liệu cá nhân, điểm đánh giá bảo mật và các kiến nghị khắc phục.

GET https://api.piiscan.pro/v1/reports/{scan_id}

Tham số trên đường dẫn (Path parameters)

Tham số Mô tả chi tiết
scan_id string Mã định danh duy nhất của phiên quét hệ thống cần truy xuất. Bắt buộc.
